# AdMob

> AdMob is Google's mobile app advertising and monetization platform. The AdMob API (admob.googleapis.com) provides programmatic access to AdMob account data, apps, ad units, mediation configuration and performance reports over REST/JSON, authorized with Google OAuth 2.0 (scopes: admob.readonly, admob.report). v1 is stable and read-only; v1beta carries the entire write surface — apps, ad units, ad unit mappings, mediation groups and mediation A/B experiments. Google publishes no OpenAPI; the machine-readable contract is a Google Discovery Document served by the API host itself.

## APIs
- [AdMob API](https://developers.google.com/admob/api): REST/JSON access to AdMob accounts, apps, ad units, mediation config and reports. Base URL https://admob.googleapis.com.

## Specs
- [OpenAPI 3.1 — v1](openapi/admob-api-v1-openapi.yml): 6 operations, 28 schemas. Converted by API Evangelist from Google's Discovery Document (revision 20260731); read-only.
- [OpenAPI 3.1 — v1beta](openapi/admob-api-v1beta-openapi.yml): 19 operations, 49 schemas. Same conversion; includes the write methods.
- [Discovery Document — v1](discovery/admob-api-v1.json): Google's first-party contract, verbatim, from https://admob.googleapis.com/$discovery/rest?version=v1
- [Discovery Document — v1beta](discovery/admob-api-v1beta.json): verbatim, from https://admob.googleapis.com/$discovery/rest?version=v1beta
- [Overlay — v1](overlays/admob-api-v1-overlay.yaml) and [Overlay — v1beta](overlays/admob-api-v1beta-overlay.yaml): API Evangelist enhancements, including the error responses Google's Discovery Document omits.
